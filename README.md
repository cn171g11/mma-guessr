# MmaGuessr · 街景猜位置游戏

一个以 [Mapillary](https://www.mapillary.com/) 为数据源的 GeoGuessr 风格地理猜谜游戏。观察世界各地随机街景，在地图上标记你猜测的位置，系统按实际距离计分。

支持五种模式：**经典 / 限时 / 多轮竞赛 / 区域限定 / 无限（闯关升级）**，并带有得分动画、距离可视化、历史最佳记录与成绩分享功能。

> 当前版本：**v1.6.0**
